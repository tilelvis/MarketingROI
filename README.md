# Marketing Attribution & ROI Analysis

This project provides a comprehensive end-to-end pipeline for performing multi-touch attribution (MTA) and return on investment (ROI) analysis for marketing campaigns using SQL and Python.

## Project Overview
Marketing attribution is the process of determining which marketing touchpoints lead to a conversion. This project implements three common attribution models:
- **First-Click**: 100% of the credit goes to the first interaction.
- **Last-Click**: 100% of the credit goes to the last interaction before conversion.
- **Linear**: Credit is distributed equally across all touchpoints in the customer journey.

The project also calculates ROI by assigning hypothetical costs to each marketing channel and comparing them with the attributed revenue.

## Dataset
This project uses a synthetic marketing dataset generated by `generate_data.py`. While the original request was for a Kaggle dataset (e.g., "Online Retail"), a synthetic dataset was chosen for this portfolio demonstration to:
1. Ensure a clear and consistent multi-touch journey for every converting user.
2. Provide a reliable, self-contained environment without external dependencies or potentially broken links.
3. Demonstrate data generation skills alongside analysis.

The dataset includes:
- `user_id`: Unique identifier for each customer.
- `timestamp`: Date and time of the interaction.
- `channel`: Marketing channel (Search, Social, Email, Display, Direct).
- `campaign`: Specific marketing campaign name.
- `conversion`: Whether the interaction resulted in a conversion.
- `revenue`: Revenue generated from a conversion.

## Project Structure
- `generate_data.py`: Creates the synthetic marketing dataset (`marketing_data.csv`).
- `setup_db.py`: Loads the CSV data into a SQLite database (`marketing.db`).
- `attribution_queries.py`: Executes SQL queries to calculate First-Click, Last-Click, and Linear attribution.
- `calculate_roi.py`: Assigns costs to channels and calculates ROI based on attribution results.
- `visualize_results.py`: Generates plots using Seaborn and Matplotlib.
- `main.py`: Orchestrates the entire pipeline from data generation to visualization.

## Getting Started
1. **Install dependencies**:
   ```bash
   pip install pandas matplotlib seaborn
   ```
2. **Run the analysis**:
   ```bash
   python main.py
   ```

## Results
After running `main.py`, the following files will be generated:
- `attribution_*.csv`: Detailed results for each attribution model.
- `roi_analysis.csv`: Comprehensive ROI metrics for each channel and model.
- `attributed_revenue.png`: Visual comparison of revenue across models.
- `attributed_conversions.png`: Visual comparison of conversion counts.
- `marketing_roi.png`: Visual comparison of ROI per channel (excluding Direct).
